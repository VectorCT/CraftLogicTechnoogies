# CraftLogic Technologies: Brand & Website Project Plan

> **Status:** Build (Phase 4) · **Owner:** Calvin Tshabalala · **Last updated:** 14 October 2026
> **Goal:** Launch a professional, conversion-focused company website for CraftLogic Technologies that positions the business as a digital systems architect for South African SMEs.

---

## 1. Brand Positioning

**Positioning statement**

> CraftLogic Technologies builds secure, scalable digital systems for growing South African businesses.

**We are:** a digital systems architect for SMEs.
**We are not:** a freelancer, "a website guy", or a design studio.

**Ideal client (added):**

- SA businesses with roughly 5–200 staff
- Running core operations on spreadsheets, email and manual processes
- Already on (or moving to) Microsoft 365 / Azure
- Decision-maker: owner, MD, operations manager or finance lead

## 3. Brand Personality

| Trait | What it means in practice |
| --- | --- |
| Professional | Corporate-ready visuals and copy |
| Structured | Clear process, consistent layout, nothing improvised |
| Technical | Backend and architecture expertise front and centre |

**Avoid:** trendy startup vibe, playful branding, overcomplicated visuals.

## 4. Logo

**Primary direction (recommended):** geometric **CL monogram**

- Clean lines, interlocking shapes, slightly angular
- Subtle circuit-inspired spacing
- Communicates structure, logic, architecture, stability

**Fallback direction:** hexagon / structured frame with a minimal node-and-line pattern inside (systems, databases, infrastructure).

**Lock-ups required:**

| Variant | Use |
| --- | --- |
| Horizontal: `[Symbol] CraftLogic` with *Technologies* beneath | Website header, documents |
| Stacked | Social avatars, square formats |
| Symbol only | Favicon, app icon, watermark |
| Mono white / mono navy | Dark and light backgrounds |

**Deliverables:** SVG (master), PNG @1x/2x, favicon set (16/32/180/512), OG/social image (1200×630).

## 6. Colour Palette

> Adjusted: committed to one value per role and added design tokens so the site can be built directly from this.

| Token | Role | Hex |
| --- | --- | --- |
| `--cl-navy-900` | Primary background (dark mode) | `#0F172A` |
| `--cl-navy-800` | Cards / surfaces | `#1E293B` |
| `--cl-azure-600` | Primary actions, links | `#2563EB` |
| `--cl-azure-500` | Hover, highlights | `#3B82F6` |
| `--cl-teal-500` | Accent (sparingly: icons, badges) | `#14B8A6` |
| `--cl-grey-200` | Neutral, borders, light text on dark | `#E5E7EB` |
| `--cl-white` | Light-mode background | `#FFFFFF` |

**Rules**

- Dark-mode-first site with azure highlights.
- Body text on navy uses `#E5E7EB`; check all text/button pairs meet **WCAG AA (4.5:1)**.
- Teal is an accent only. Never more than ~5% of a screen.

## 7. Messaging Framework

**Primary homepage headline:** *We Build the Systems That Run Your Business*
**Sub-headline:** *Custom software and business systems for South African SMEs. Secure, structured and built to scale.*

Supporting headlines (section titles, ads):

- Replace Spreadsheets with Smart Systems
- Secure. Structured. Scalable.
- Custom Software & Business Systems Built to Scale

**Core messaging pillars**

1. **Engineering-first:** "We architect before we build."
2. **Built for scale:** "No shortcuts. No fragile systems."
3. **Long-term partnership:** "We don't disappear after launch."
4. **Microsoft-based infrastructure:** Secure, enterprise-grade, built on Azure and Microsoft 365.

**Elevator pitch**

- Long: *CraftLogic Technologies helps South African businesses replace manual processes with secure, custom-built software systems designed for long-term growth.*
- Short: *We build structured digital systems that help businesses scale properly.*

## 8. Brand Voice

**Write like an engineer:** clear, direct, no hype, no fluff.

| Use | Avoid |
| --- | --- |
| Practical language | Buzzwords |
| Measurable outcomes ("cut month-end admin from 3 days to 4 hours") | "Revolutionary", "disruptive", "cutting-edge" |
| Clear benefits | Vague promises |
| South African English (organise, colour, optimise), prices in ZAR | US spelling, USD pricing |

---

## 9. Visual Style

**Use:** abstract tech backgrounds, structured/grid patterns, clean office environments, dashboard and UI visuals, architecture-style diagrams.
**Avoid:** smiling call-centre stock photos, handshake photos.

> Added: prefer real (anonymised) screenshots of systems built over stock imagery wherever possible.

## 11. Technical Approach

> Added: the original concept had no build plan. This is the recommended stack, aligned with the Microsoft/Azure positioning.

| Area | Recommendation | Notes |
| --- | --- | --- |
| Front end | **Nuxt 4** (Vue 3 Composition API, TypeScript) + **Pinia** (UI state) + **TanStack Query** (server state) | Decided in T-301. Code in `craftlogic-web/`; see `docs/ARCHITECTURE.md`. |
| Styling | Tailwind CSS with brand tokens | Tokens from section 6 |
| Hosting | **Azure Static Web Apps** (static) or **Azure App Service** (Razor) | Free / low tier to start |
| Contact form | Nitro server route (`/api/contact`) → email via Microsoft Graph / SendGrid | Add honeypot + Cloudflare Turnstile or reCAPTCHA |
| Domain & DNS | `.co.za` domain; DNS via Azure DNS or Cloudflare | HTTPS everywhere |
| Analytics | Microsoft Clarity and/or GA4 | Behind cookie consent |
| CI/CD | GitHub Actions → Azure | Deploy on merge to `main` |
| Source control | Private GitHub repo | |

**Non-functional targets**

- Lighthouse ≥ 90 on Performance, Accessibility, Best Practices, SEO
- Fully responsive (360px → 1920px)
- WCAG 2.1 AA
- POPIA-compliant: privacy policy, consent checkbox on forms, cookie banner
- Page weight < 1 MB on Home
